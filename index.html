01 — About

I started in motion design, then learned to code to build the tools I wanted. Two years and three working products later, I still build the whole thing myself — database, backend, and the interface people actually touch. Based in Tashkent, Uzbekistan, and looking for my first developer role — remote or on-site.

02 — Selected work

Cutlass — the AI and the editor
hold the same controls

A video editor where every edit is one command in a single registry — the interface fires them, and the AI fires the same ones. Built from scratch: my own Rust core and my own interface, down to the timeline and the render pipeline.

Read the case study
01Windows app

Shorts Pilot — Instagram to YouTube, paced

A Windows desktop app that watches the clipboard: copy a reel link and it downloads the clip, works out which channel it belongs to, and releases it on a per-channel interval so a burst of links doesn't become a burst of uploads.

  • Python
  • JavaScript
  • YouTube Data API
  • pywebview

Source isn't public by default — the site has a request page, and I hand out an access code to anyone with a good reason to read it.

02Beta

Galera — support the artists behind the art

A membership platform for digital artists: work stays public, supporters subscribe to monthly tiers and unlock the studio — 4K files, PSDs, process videos. Accounts, pledges and per-artwork access are enforced in the database with row-level security.

  • JavaScript
  • Supabase
  • Netlify
Source
03Live

Nowhere Central — an ambient site to fall asleep to

Generated soundscapes, slow drifting visuals, a sleep timer and a night mode that dims when you stop moving. Zero dependencies — every world is a raymarched GLSL shader and every sound is synthesised at runtime from maths.

  • JavaScript
  • WebGL / GLSL
  • Web Audio
  • Node.js
